This package contains the complete, compilable Elsevier CAS single-column LaTeX manuscript:
"AI-Driven Spatiotemporal Modeling and Downscaling of Urban Heat Island Dynamics in Metropolitan Mumbai"

Directory Structure:
- Elsevier_s_CAS_LaTeX_Single_Column_Template.tex : Main manuscript file
- cas-sc.cls, cas-common.sty, cas-model2-names.bst: Elsevier CAS LaTeX single-column document class files
- thumbnails/                                     : Required template icons (cas-email.jpeg, etc.)
- figs/                                           : High-resolution publication figures (Fig 1 through Fig 7)
- references.bib                                  : Bibliography file (to be populated with verified references)

Instructions for Overleaf:
1. Go to https://www.overleaf.com/project
2. Click "New Project" -> "Upload Project"
3. Upload "mumbai_uhi_elsevier_manuscript_overleaf.zip"
4. Ensure the compiler is set to pdfLaTeX or XeLaTeX / LuaLaTeX.
5. Recompile!
